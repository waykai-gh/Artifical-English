# Внутренняя документация

Этот каталог — единая точка правды по эксплуатации проекта. Здесь фиксируются значимые факты, а не каждый запуск команды.

- [`STATUS.md`](STATUS.md) — текущее состояние production, ограничения, риски и ближайшие задачи.
- [`OPERATIONS.md`](OPERATIONS.md) — архитектура, мониторинг, выпуск версии и порядок восстановления.
- [`DEPLOYMENTS.md`](DEPLOYMENTS.md) — журнал фактических публикаций и откатов.
- [`INCIDENTS.md`](INCIDENTS.md) — подтверждённые сбои, деградации и важные эксплуатационные события.
- [`../CHANGELOG.md`](../CHANGELOG.md) — изменения продукта по версиям.

Правила обязательного обновления этих файлов находятся в [`../AGENTS.md`](../AGENTS.md). Секреты, адреса сервера, Telegram ID и тексты пользователей сюда не записываются.
